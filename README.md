# Community Fix-It

Community Fix-It is an Android app that helps residents report local issues such as potholes, broken streetlights, water leaks, and illegal dumping. Residents can track the progress of their reports and read responses from municipal officers.

## Features

- **Residents** can submit reports, attach a photo or location, and view or delete their own reports.
- **Municipal officers** can review all reports on the device, update their status, and add response notes.
- **Report progress** moves through **Reported → In progress → Fixed**. The app can display a local notification when a status changes.
- **Map handoff** opens a report’s saved location in Google Maps.

## Built with

Flutter and Dart for the Android app, Firebase Authentication for email and password sign-in, and Cloud Firestore for account role lookup.

## Current scope

Reports are stored locally on the Android device. Cloud report storage and syncing across devices are planned for a future version.
